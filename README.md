# PROYECTO ALL-CAMPO
# Problematica inicial
El supermercado All-Campo, ubicado en la localidad de Rafael Uribe, se dedica a la venta de productos de consumo diario, ofreciendo alimentos perecederos y no perecederos, bebidas, productos de aseo personal y otros artículos de primera necesidad. El establecimiento cuenta con un jefe principal, un subjefe y cinco empleados encargados de la atención al cliente y el proceso de ventas; El supermercado All-Campo presenta problemas como pérdida de información, errores en los registros y dificultades para consultar los datos de manera rápida y precisa, debido a que gran parte de la información relacionada con las ventas se registra de forma manual mediante cuadernos y hojas físicas. En estos registros se anotan las ventas realizadas y algunos movimientos de dinero.
